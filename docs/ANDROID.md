Create an Android port.

Determine which programming languages, SDKs, etc.
are needed and/or are the best choices to use for
creating the Android port. Present recommendations
and ask user to confirm.

Must have full feature parity with original project.

Determine features required for MVP first, create
plan for MVP implementation, and ask user to confirm
before implementing MVP.

Determine remaining features needed for full feature
parity with original project, and for each feature
determine which features depend on that feature and
which features are required for that feature, then
create a roadmap with small, manageable sets of
features to implement to incrementally increase
progress towards feature parity with the original
project.

Use git for source control.

Add + commit changes for each feature that is
implemented.

Work on one set of features at a time.

After each set of features is implemented, display
summary of what was completed and ask the user if
they wish to proceed.

Keep a log of work completed and work remaining
and update after each feature is implemented.

Write a plan before implementing each set of features
and save to the project directory.

Do not delete plan files after implementing them.

Consider the MVP the first feature set to implement.

Pause after implementing MVP, display progress summary
and ask user if they wish to proceed.
